# Лабораторная работа №1 — Исследование MLP

## Описание

В работе реализована многослойная нейронная сеть (MLP) на **PyTorch** для решения задачи бинарной классификации на синтетическом наборе данных `make_moons`.

Цель работы — исследовать влияние глубины сети, функций активации, инициализации весов и оптимизаторов на качество обучения.

## Данные

Используется `make_moons` из библиотеки `scikit-learn` со следующими параметрами:

- Количество объектов: 2400
- Уровень шума: 0.25
- `random_state=2026`
- Train: 1440 объектов (60%)
- Validation: 480 объектов (20%)
- Test: 480 объектов (20%)

Признаки стандартизируются с помощью `StandardScaler`, обученного только на тренировочной выборке.

## Эксперименты

Проведено 12 запусков: шесть конфигураций нейронной сети с двумя значениями `seed` (11 и 29).

| Конфигурация | Скрытые слои | Активация | Инициализация | Оптимизатор |
|---|---:|---|---|---|
| A | 6 | Sigmoid | Xavier | Adam |
| B | 6 | Tanh | Xavier | Adam |
| C | 6 | ReLU | Xavier | Adam |
| D | 6 | ReLU | He | Adam |
| E | 6 | ReLU | He | SGD |
| F | 1 | ReLU | He | Adam |

Каждая модель обучалась 100 эпох. Размер скрытых слоёв — 32 нейрона, функция потерь — `CrossEntropyLoss`.

Для конфигураций A, C и D дополнительно измерялись нормы градиентов на эпохах 0, 20 и 100.

## Результаты

Наилучшая конфигурация выбиралась по среднему `validation loss` двух запусков. Лучшей оказалась **F (1 скрытый слой, ReLU, He, Adam)**.

Для итогового тестирования использована модель с `seed=29`.

| Метрика | Значение |
|---|---:|
| Validation loss | 0.1676 |
| Test loss | 0.1314 |
| Test accuracy | **95.00%** |

Результаты показывают, что увеличение числа скрытых слоёв не всегда улучшает качество классификации. В данном эксперименте неглубокая сеть показала наилучшее качество на валидационной выборке.

## Запуск

Для запуска необходим Python 3 и установленные зависимости.

1. Клонировать репозиторий:

   `git clone git@github.com:andrew52522/lab_DLNN_first.git`

2. Перейти в папку проекта:

   `cd lab_DLNN_first`

3. Создать и активировать виртуальное окружение:

   `python3 -m venv .venv`

   `source .venv/bin/activate`

4. Установить зависимости:

   `pip install -r requirements.txt`

5. Открыть `notebook.ipynb` в Jupyter Notebook или VS Code и выполнить ячейки последовательно. При необходимости установить Jupyter командой `pip install jupyterlab`.

Обучение выполняется **на CPU**, использование GPU не требуется.

Итоговая точность на независимой тестовой выборке составила **95%**.
